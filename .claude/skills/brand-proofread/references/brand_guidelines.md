# 株式会社サンプル ブランドガイドライン（表記ルール集）

## 1. 自社の呼称

- **正しい表記：「当社」**
- 誤った表記：「弊社」（使用禁止）
- 例：「当社の製品をご利用いただき、ありがとうございます。」

## 2. 製品名の表記

- **正しい表記：「ABCDE」**（半角・スペースなし・すべて大文字）
- 誤った表記：「ABC DE」「abcde」「ABC」（いずれも使用禁止）
- 例：「ABCDEをご導入いただいているお客様へのご案内です。」

## 3. 問い合わせ先の案内

- **正しい表記：「お問い合わせフォームよりご連絡ください」**
- 誤った表記：「お問い合わせください」のみ（フォームへの誘導が必須）
- 例：「ご不明な点がございましたら、お問い合わせフォームよりご連絡ください。」

## 4. 会社名の表記

- **正しい表記：「株式会社サンプル」**（略称の使用禁止）
- 誤った表記：「サンプル」「サンプル社」（いずれも使用禁止）
- 例：「株式会社サンプルは、2015年に設立されました。」

## 5. その他の注意事項

- お客様への文書では必ず敬体（ですます調）を使用する
- 数字は半角で統一する（全角数字の使用禁止）
